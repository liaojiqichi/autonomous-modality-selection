# Active architecture

Final-proposal configuration -> verified evidence packages -> scenario/model/draw
preparation -> actual Colab selection and generation -> A/P annotation -> paired analysis.

Domain assets and question schemas remain version 2.0 for evidence-package reuse.
Richness annotation has a distinct breaking version richness-annotation-3.0; old C
fields are rejected rather than silently ignored. Scores use solution-richness-ap-2.0.

Scientific modality is distinct from representation. The evidence_views_v1 extension
is reusable and requires no duplicate raw downloads. Do not copy numeric rasters merely
to create a new experiment manifest. The generator whitelist excludes selection rationale.

Rule selection and fixed-pair trials are useful auxiliary controls, not the agent.
The existing benchmark verification/extraction modules remain because current packages
and tests depend on them. Historical reports are not active protocol instructions.

Remaining gates and exact preparation command are documented in primary_experiments.md.
